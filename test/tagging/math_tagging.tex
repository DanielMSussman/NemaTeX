This file uses examples from the mathml core W3C editor's draft, 27 July 2026. %https://w3c.github.io/mathml-core/
That page has a number of examples of formula and their corresponding mathml representation, which we take to be ground truth.
I've only just started, and thus have only a few examples so far. The examples below mix inline and display math.
As an example of how brittle this suite is, the order of math below must be the same as the ordering of the corresponding json file, which holds the expected representation. %reference_math_tagging.json

Standalone superscript: $x^2$.

Standalone subscript: $a_i$.

Integral with nolimits (side scripts): $$\int_0^1 x$$

Partial limits (under only): $$\sum_{i=0} x$$

Overline: $\overline{x + 1}$.

Binomial coefficient: ${n \choose k}$.

A simple square root: $\sqrt{x}$.

Square root of a sum: $\sqrt{x^2 + y^2}$.

A cube root: $\root 3 \of {x}$.

An n-th root: $\root n \of {1+x^n}$.

$$\root 3 \of {\sqrt{1 \over 2} + 4} + 0$$

A fraction with addition: ${1 \over 2} + 3$.

$${a \over b}$$

Subscript and superscript: $x_1^2 + 3$.

$$\sum_{i=0}^n a_i$$

Fenced fraction: $\left( {a \over b} \right)$.

Fenced sum: $\left( x + 1 \right)$.

$$ {A \over 2} = \pmatrix{
  1 & 2 & 3 \cr
  4 & 5 & 6 \cr
  7 & 8 & 9 \cr
} $$

Phantom expression: $x + \phantom{y} + z$.

Explicit math spacing: $x \quad y$.

Text in math mode: $x = \hbox{true or false}$.

Empty base (prescripts): ${}_1^2 x$.
