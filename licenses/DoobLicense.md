# Michael Doob license (gentle.tex)

This file lives in the `assets/sample/` dir, as a moderately long `plain.tex`-based document. Fun for timing / profiling a workload more representative than the trip test.
`gentle.tex` was written by Michael Doob (University of Manitoba), and can be found here: [CTAN: info/gentle](https://ctan.org/pkg/gentle).
It's license on CTAN is listed as "Free license not otherwise listed". The text in the file itself:
